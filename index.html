📖 How to set up chat entries
  1. Click 💬 Take entries from chat. The dot turns green when it's live.
  2. Click Show Slot Tools command and copy the line (it holds your private key, so don't show it on stream).
  3. In Slot Tools, open Add Custom Command: Command blingo, Response = the line you copied, Permission Everyone, then Add.
  4. Keep this tab open. Viewers type !blingo to join while this setup screen is showing, and names land in the box above.
  5. Also works: !blingo count, !blingo list, !blingo status (shows the winner after the game).
  6. Optional !blame: add a second Slot Tools command blame with the same line, but change the end from q=$(query) to q=blame (the box below shows it). It answers "you blame" a random entry, any time, and never joins anyone.
  7. Tab closed = the command stays quiet. Same browser keeps the same key; a new computer or cleared browser data means pasting a new command.
